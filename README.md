# @utexo/wdk-wallet-rgb

Private review candidate for the on-chain RGB wallet SDK. It uses a watch-only RGB BFA engine and an application-owned signer. Node and Android Bare use the same pinned Electrum-only native graph.

See the [candidate guide](CANDIDATE.md) for build, API, authorization and recovery. The package currently admits isolated regtest endpoints. The [qualification register](QUALIFICATION.md) records release gates and the intended Iris integration contract.
